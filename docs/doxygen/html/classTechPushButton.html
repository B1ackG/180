TechPushButton::TechPushButton ( QWidget *  parent = nullptr)
explicit

构造 TechPushButton

可配置样式、动画与多种特效的按钮控件，支持文本/图标组合，适合科技风 UI。 内部使用 QPropertyAnimation 驱动发光/脉冲/扫描线等效果，绘制开销 随效果复杂度增加而上升。

参数
parent父控件。
注解
默认不启用所有特效，需通过对应 enableXXX 接口开启。
警告
启用大量动画（尤其多个按钮同时动画）可能带来 CPU/GPU 开销， 在性能敏感界面应限制并发动画数量或降低帧率。
