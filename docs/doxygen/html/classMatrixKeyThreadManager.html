◆ start()

bool MatrixKeyThreadManager::start ( const QString &  device = "/dev/input/event0")

启动监控线程

参数
device输入设备路径，默认为 "/dev/input/event0"。
返回
true 表示成功启动并开始监控，false 表示失败（例如无法打开设备）。
注解
内部会在新线程中创建 MatrixKeyMonitor 并将其移入该线程。
警告
若设备被其它进程占用，可能无法打开导致启动失败。
