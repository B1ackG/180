◆ TechSliderEdit()

TechSliderEdit::TechSliderEdit ( QWidget *  parent = nullptr)
explicit

构造 TechSliderEdit 控件

提供带标签的滑块 + 编辑框组合控件，适用于需要同时显示数值与滑块控制的场景。 内部通过 m_conversionFactor 支持小数精度，通过 m_slider 与 m_lineEdit 双向同步， 并支持将值映射到 Modbus 地址以便与外部设备联动。

参数
parent父控件，通常传入 this。
注解
构造不会触发初始值改变信号，建议创建后调用 setRange() 与 setPrecision() 进行初始化。
警告
在高频率更新（>50Hz）场景下，频繁触发 UI 重绘会影响性能，应合并更新或使用后台数据采样。
自从
1.0.0

使用示例:

auto *s = new TechSliderEdit(parent);
s->setRange(0, 100);
s->setPrecision(1);
s->setValue(50.0);

设置可选范围

将滑块与文本编辑的允许范围设置为 [min, max]。 内部会自动调整 m_slider 的步长并校准当前值到新范围内。

参数
min最小值，必须小于 max。
max最大值，必须大于 min。
注解
当 min >= max 时函数会忽略请求并在调试模式下打印警告。
警告
修改范围可能触发 valueChanged()，调用方应准备接收该信号。
