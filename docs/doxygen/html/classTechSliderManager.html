TechSliderManager::TechSliderManager ( QObject *  parent = nullptr)
explicit

构造 TechSliderManager

管理页面中多个 TechSliderLabel / TechSliderEdit 的配置、缓存与批量更新。 典型用法是从配置文件中加载 TechSliderConfig，然后调用 setupPageUI() 在目标页面创建并缓存标签对象，随后通过 updateValues() 批量刷新显示。

参数
parent父对象（一般传 qApp 或主窗口指针）。
自从
1.0.0
注解
本管理器维护标签对象指针缓存（m_labelCache），请在页面关闭时 清理或确保页面生命周期与本管理器相匹配以避免悬挂指针。
