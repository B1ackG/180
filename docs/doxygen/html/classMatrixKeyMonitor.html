◆ startMonitoring()

bool MatrixKeyMonitor::startMonitoring ( )

开始监控输入事件

打开设备文件并通过 QSocketNotifier 监听事件，可在独立线程中运行以避免阻塞主线程。

返回
true 表示监控已成功启动
警告
若设备路径无效或权限不足则会返回 false 并发出 errorOccurred()。
