连接到 Modbus TCP 服务器

建立到指定 host:port 的 TCP 连接并设置从站 ID。

参数
host目标主机 IP 或域名。
port目标端口（通常为 502）。
slaveIdModbus 从站 ID，默认 1。
返回
true 表示发起连接成功（不等于已完成握手），连接建立后会发出 connected()。
注解
若需要 DNS 支持或加密通道，请在实现中扩展。
