◆ TechSpeedGauge()

TechSpeedGauge::TechSpeedGauge ( QWidget *  parent = nullptr)
explicit

构造 TechSpeedGauge

可配置样式与动画的速度仪表控件，支持平滑动画过渡与多种视觉特效。 内部通过 m_valueAnimation 平滑过渡目标值，通过缓存 m_backgroundCache 减少重复绘制开销。

参数
parent父控件
注解
若改动几何尺寸，请在适当时机清理或重建 m_backgroundCache。
警告
长时间启用高帧率动画会增加 CPU 与 GPU 负载，必要时降低精度或使用较慢的动画节奏。
自从
1.0.0
