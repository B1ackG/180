# 步进目标与外部触发联动技能

## 目标
在“步进模式 + 指定运动模式 + 特定目标”下，建立统一的外部触发与步进值写入流程。

## 触发条件
- 当前页面为动作执行页
- 当前运行模式满足步进前置条件
- 当前目标已切换到外设通道目标

## 行为规则
1. 目标切换时
- 置位“目标选择态”
- 将当前步进输入值同步到外设步进输入寄存器

2. 外部触发按下时
- 置位“触发态”
- 将步进值写入外设执行寄存器
- 支持按键方向映射（正向/反向）

3. 外部触发释放时
- 清除“触发态”
- 防止触发位长期保持导致重复触发失效

4. 步进值变化时（目标不变）
- 实时同步最新步进值到外设输入寄存器

## 设计理由
- 将“目标选择态”和“触发态”解耦
- 触发位必须具备上升与回落，保证可重复触发
- 输入值同步与触发分离，避免旧值执行

## 注意事项
- 对小数步进值需统一取整策略
- 对负向值需统一编码策略
