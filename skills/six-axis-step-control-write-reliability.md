# 多轴步进写入可靠性技能

## 目标
总结为了让多轴步进控制稳定执行所采用的时序与保护策略。

## 代码位置
- 主流程：外部键动作处理函数
- 文件：业务主窗口逻辑文件
- 关键语义：目标轴寄存器、步进值寄存器、触发位寄存器

## 实施策略

### 1) 分阶段写入顺序（先目标，再值，再触发）
- 按下外部键后，先写目标轴。
- 然后用延时链写步进值，最后再用延时链写触发位。
- 这样做是为了避免 PLC 扫描窗口内出现“触发先到、值还未稳定”的时序问题。

### 2) 延时与重发策略
- 对步进值与触发位分别采用“首次写 + 补写”策略。
- 延时窗口按现场控制器扫描周期调参，不固定某个数值。

### 3) 释放时的双写清零
- 按键释放时立即清零步进值与触发位。
- 短延时后补写一次清零。
- 作用：降低按键快速切换或抖动导致的残留触发态风险。

### 4) 去重与并发保护（非延时）
- 去重：`m_sixAxisExternalKeyPressed[keyNumber]` 防止同一键重复按下重复写入。
- 活跃键：`m_sixAxisActiveKey` 保证只响应当前活动按键。
- 序列号：`m_sixAxisExternalWriteSeq` 每次新动作递增；所有延时回调先校验序列号，不匹配即丢弃，避免旧回调串写。
- 回调三重校验：序列号一致 + 活跃键一致 + 当前键仍处于按下，三者都满足才真正写寄存器。

### 5) 输入与方向处理
- 外部键映射到轴索引。
- 按键方向映射为正向/反向步进。
- 步进输入解析失败时拒绝写入。

## 结论
步进控制稳定执行的核心不是单次写入，而是“分阶段时序 + 重发 + 释放复位 + 去重/序列号防串写”组合策略。
