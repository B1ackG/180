# 六自由步进写入可靠性技能

## 目标
总结为了让六自由步进控制稳定“写进去”所采用的延时与保护策略。

## 代码位置
- 主流程：`MainWindow::handleMatrixKeyAction(int keyNumber, bool pressed)`
- 文件：`mainwindow.cpp`
- 关键寄存器：`614`(目标轴), `601`(步进值), `615`(触发位)

## 实施策略

### 1) 分阶段写入顺序（先目标，再值，再触发）
- 按下外部键后，先立即写 `614=axisIndex`。
- 然后用延时链写 `601`，最后再用延时链写 `615=1`。
- 这样做是为了避免 PLC 扫描窗口内出现“触发先到、值还未稳定”的时序问题。

### 2) 延时与重发策略
- `QTimer::singleShot(20ms)`：第一次写 `601`。
- `QTimer::singleShot(70ms)`：第二次补写 `601`（重发）。
- `QTimer::singleShot(120ms)`：第一次写 `615=1`。
- `QTimer::singleShot(180ms)`：第二次补写 `615=1`（重发）。

### 3) 释放时的双写清零
- 按键释放时立即写：`601=0`, `615=0`。
- 再 `35ms` 后补写一次：`601=0`, `615=0`。
- 作用：降低按键快速切换或抖动导致的残留触发态风险。

### 4) 去重与并发保护（非延时）
- 去重：`m_sixAxisExternalKeyPressed[keyNumber]` 防止同一键重复按下重复写入。
- 活跃键：`m_sixAxisActiveKey` 保证只响应当前活动按键。
- 序列号：`m_sixAxisExternalWriteSeq` 每次新动作递增；所有延时回调先校验序列号，不匹配即丢弃，避免旧回调串写。
- 回调三重校验：序列号一致 + 活跃键一致 + 当前键仍处于按下，三者都满足才真正写寄存器。

### 5) 输入与方向处理
- 轴映射：`○1/2->轴1 ... ○11/12->轴6`。
- 奇数键取负值（反向），偶数键正值。
- 步进值来源 `lineEdit_SixAxies_StepValue`，解析失败直接忽略写入。

## 结论
六自由步进“能写进去且稳定”的核心不是单次写寄存器，而是“分阶段时序 + 重发 + 释放复位 + 去重/序列号防串写”组合策略。
