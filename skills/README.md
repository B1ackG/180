# Skills 使用说明

## 什么是 skills
`skills` 目录用于沉淀“可复用、可复制”的实现套路，减少重复排障。
当前约定：只保留抽象逻辑与通用流程，不写死具体地址、寄存器号、IP、按钮编号。

## 当前可用技能
- `six-axis-step-control-write-reliability.md`
- `agv-battery-charging-indicator-156.md`
- `homepage-agv-step-target-and-external-keys.md`
- `agv-bit-write-safety-gate.md`

## 什么时候使用
- 需求描述与某个技能主题高度一致
- 同类问题重复出现（如寄存器时序、触发位、模式门禁）
- 需要快速回忆“正确链路”和“踩坑点”

## 如何使用
1. 先定位最接近的技能文件
2. 按技能里的“触发条件/行为规则/排障清单”逐项核对
3. 在新需求实现时复用关键结构
4. 实现后按技能中的验证点回归检查

## 在 Copilot 中怎么调用
1. 在提问里明确引用技能文件路径
2. 指定“按该技能实现/重构/排查”
3. 再给当前需求的具体映射（例如本次要落到哪个寄存器）

示例提问：
- 按 skills/按位写入安全门禁技能重构当前 AGV 触发逻辑。
- 按 skills/状态驱动充电视觉技能排查为什么状态到了但 UI 没变化。

## 命名建议
- 文件名采用 `领域-场景-动作.md`，例如 `agv-battery-charging-indicator-156.md`
- 内容结构固定：目标 / 触发条件 / 行为规则 / 排障清单 / 经验要点

## 维护建议
- 每次完成一个高价值修复后更新对应 skill
- 如果同一主题已有 skill，优先增补而不是新建重复文件
- 技能必须写“为什么这样做”，而不只写“做了什么”
