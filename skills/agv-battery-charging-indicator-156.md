# 状态驱动充电视觉技能

## 目标
将设备状态位稳定映射为 UI 的“充电中”视觉反馈。

## 适用场景
- 需要把通讯层状态同步到界面动画
- 链路存在“请求已发出但界面无变化”的排障需求

## 关键链路
1. 轮询层
- 对充电状态采用低频轮询
- 轮询请求独立节奏发送，避免和高频业务请求并发

2. 解析层
- 在响应分发中显式纳入充电状态字段
- 将原始值映射为统一业务语义（例如 `charging_state`）
- 发出统一的数据变化信号

3. UI层
- 监听统一状态变化信号
- 将状态值转为布尔充电态并驱动组件

4. 视觉层
- 充电态显示明确图标
- 非充电态回退为静态显示
- 使用轻量动画增强识别度

## 排障清单
- 请求是否有发有收
- 解析层是否把目标状态纳入分发
- 信号槽链路是否完整触发
- UI控件是否真正被定位到并更新

## 经验要点
- “数据到达”不等于“界面更新”，必须逐层验链路。
- 关键状态建议低频独立轮询，优先保证稳定性。
